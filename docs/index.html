CoCreate-waveform

Declarative audio waveform analysis and canvas visualization using the Web Audio API.

Install

 
npm i @cocreate/waveform

Or you can use cdn link: 

<script src="https://cdn.CoCreateJS.com/waveform/latest/CoCreate-waveform.min.js"></script>

Usage

Render live audio samples on a canvas using waveform-query. 

                                <button type="button" waveform-query="$document #wave" waveform-visualization="history" waveform-fft-size="2048" aria-label="Toggle waveform">Start / stop</button>
<canvas id="wave" width="960" height="240" aria-label="Live waveform"></canvas>

Render live audio samples on a canvas using waveform-query.

Attributes

  • waveform start / stop / end optional

    Set start or stop to control analysis. The component sets end after cleanup. Use waveform-query to select the target canvas.

  • waveform-visualizationline / bars / history

    Select a built-in canvas style. Line is the default, bars mirrors the current signal around the center, and history scrolls recent audio levels from right to left and remains visible after stopping.
